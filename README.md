# Awesome Online Tools (wtoolskit)

> A curated catalog of **free, browser-based online tools** from the **wtoolskit** family — a collection of privacy-first web apps where everything runs client-side. Your files and text never leave your device, and no signup is required.

![Tools](https://img.shields.io/badge/tools-200%2B-blue) ![Products](https://img.shields.io/badge/products-5-important) ![Languages](https://img.shields.io/badge/languages-16-important) ![Client-side](https://img.shields.io/badge/client--side-100%25-success) ![License](https://img.shields.io/badge/license-CC0--1.0-blue.svg)

## What is this?

This list is curated and maintained by the team behind the **[wtoolskit](https://www.wtoolskit.com/)** family of privacy-first web apps. It aggregates **198+ free tools** across five products:

- **[WebTools](https://www.wtoolskit.com/)** — a general-purpose online toolbox with 117 utilities across 10 categories.
- **[CodeJet](https://code.wtoolskit.com/)** — a free online code editor with live preview.
- **[APIPulse](https://api.wtoolskit.com/)** — a free online API testing & debugging tool with CORS proxy.
- **[GameHub](https://game.wtoolskit.com/)** — 60 classic browser games.
- **[PeerBeam](https://rtc.wtoolskit.com/)** — 19 WebRTC peer-to-peer tools.

All products share the same philosophy: **100% client-side, no account, no upload, works instantly in any modern browser.**
